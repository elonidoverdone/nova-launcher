# Nova — свой лаунчер Minecraft + мод NovaFX

Лаунчер **Nova Launcher** (Go + WebView2, Windows) и клиентский Fabric-мод **NovaFX** для Minecraft **26.3**. По желанию лаунчер ставит сборку оптимизации **Fabulously Optimized**.
Написаны с нуля. Чужой код, сервера и защита Pulse не используются.

## Что внутри

```
nova/
  dist/NovaLauncher.exe   готовый лаунчер (Windows 10/11, x64)
  launcher/               исходники лаунчера (Go)
  mod/                    исходники мода NovaFX (Fabric, Java 25)
  build-mod.bat           собрать мод локально (нужен JDK 25)
  .github/workflows/      автосборка мода и лаунчера на GitHub
```

## Быстрый старт

1. Соберите мод одним из двух способов (подробнее ниже) и положите `novafx-1.0.0.jar` **в ту же папку, что и `NovaLauncher.exe`**.
2. Запустите `NovaLauncher.exe`. Аккаунт можно добавить во вкладке «Аккаунты» или прямо в игре.
3. Нажмите «Играть». При первом запуске лаунчер сам скачает:
   - Minecraft 26.3 с серверов Mojang,
   - Fabric Loader (последний стабильный),
   - Java от Mojang (ту, которую требует версия),
   - Fabulously Optimized (или только Fabric API, если сборка выключена).

   Потом он скопирует NovaFX в `mods`.
4. В игре нажмите правый Shift, чтобы открыть меню визуалов.

Данные лежат в `%APPDATA%\.nova`: игра в `game`, логи в `logs`.

## Мод NovaFX

**Меню прямо в игре.** Все настройки визуалов находятся в самой игре, а не в лаунчере. Нажмите **правый Shift** в мире, в меню паузы или сразу на главном экране после запуска Minecraft. Подсказка висит в левом верхнем углу главного экрана.

Меню своё: скруглённые панели, вкладки, анимированные переключатели, ползунки, выбор из списка и палитра цветов. Изменения сохраняются сразу. Клавишу можно переназначить в стандартных настройках управления.

| Вкладка | Что настраивается |
|---|---|
| Удары | вкл/выкл, только по игрокам, вид частиц (криты, магия, сердца, огонь, синий огонь, искры, звёзды, тотем, снег, фейерверк), форма (взрыв, кольцо, спираль), количество, скорость, звук, громкость, тон |
| Добивание | эффект (столб света, души, взрыв, тотем) и звук |
| Хитмаркер | вкл/выкл, цвет при попадании и при добивании |
| Цель | метка цели вкл/выкл, только игроки, форма (гексаграмма, пятиконечная звезда, ромб, кольцо), цвет, размер, скорость и направление вращения (по часовой или против), свечение |
| Музыка | текст песни, случайное место, объёмные буквы и их разброс, размер, скорость букв, цвет, подложка и её прозрачность, сдвиг по времени |
| Меню | цвет акцента самого меню |

Ещё две клавиши: **H** включает и выключает эффекты, **J** переключает стиль частиц.

**Метка цели.** Когда в прицеле игрок или моб, до которого вы достаёте ударом, на нём крутится синяя шестиконечная звезда. Она плавно появляется, подстраивает размер под расстояние, вспыхивает при каждом ударе и гаснет, когда цель уходит из прицела. Мод не видит сквозь стены и не делает ничего сверх того, что игра и так знает о цели под прицелом.

**Текст песни.** На экране только та строка, которую поют сейчас. Она печатается по буквам. Буквы объёмные, с глубиной: каждая влетает, разворачиваясь как карточка, встаёт в своё место со своим наклоном и плавно покачивается. Подложка скруглённая и растёт вместе с текстом. Для каждой новой строки выбирается случайное место, но не на прицеле и не на хотбаре, и плашка плавно переезжает туда, а старая строка гаснет. Если выключить «Случайное место», строки будут стоять справа сверху.

Откуда берётся текст:
1. Яндекс Музыка (приложение или вкладка браузера) показывает трек в медиапанели Windows. Лаунчер читает оттуда название, исполнителя и позицию.
2. Синхронизированный текст лаунчер ищет в открытой базе [LRCLIB](https://lrclib.net).
3. Результат лаунчер пишет в `game\config\novafx-lyrics.json`, мод читает этот файл.

Пока вы играете, лаунчер должен быть открыт: при запуске игры он просто сворачивается. Если для трека в LRCLIB нет синхронного текста, строки не появятся.

## Аккаунты в игре

Текущий аккаунт виден в правом верхнем углу главного экрана Minecraft и экрана сетевой игры. Нажмите на него, откроется окно аккаунтов:
- **переключение в один клик:** игра сразу заходит под выбранным аккаунтом, перезапускать её не нужно;
- **добавить офлайн-ник;**
- **войти через Microsoft:** код показывается прямо в игре, страница Microsoft открывается в браузере;
- **удалить аккаунт.**

Аккаунты хранит лаунчер, токены Microsoft зашифрованы Windows. Мод получает их по локальному каналу только с этого компьютера, по секретному ключу из `game\config\nova-bridge.json`. Поэтому выбор запоминается: в следующий раз игра запустится под последним выбранным аккаунтом. Лаунчер при этом должен быть открыт.

Если аккаунтов ещё нет, лаунчер всё равно запустит игру под офлайн-ником Player, а окно входа откроется само на главном экране.

Входу Microsoft и в игре нужен Client ID (см. раздел ниже): Microsoft пускает только через одобренное приложение, где бы ни происходил вход.

Подмена сессии в запущенной игре сделана по образцу открытого мода [Auth Me](https://github.com/axieum/authme) (MIT), лицензия лежит в `mod/THIRD_PARTY_NOTICES.txt`.

## Fabulously Optimized

В настройках лаунчера включён переключатель **Fabulously Optimized**. При каждом запуске лаунчер ставит или обновляет эту сборку под выбранную версию: Sodium, Iris, Lithium, ImmediatelyFast, EntityCulling, Mod Menu, Zoomify и другие.

- Версию Fabric Loader лаунчер берёт ту, которую требует сборка.
- Fabric API идёт в составе сборки, второй раз он не ставится.
- Ваши изменения в конфигах сборки при обновлении не затираются.
- Моды старой версии сборки удаляются.

NovaFX работает вместе со сборкой: в моде нет миксинов, а HUD и меню рисуются через Fabric API. Правый Shift в Fabulously Optimized ни на что не назначен.

Под 26.3 Fabulously Optimized пока выходит только в виде альфа- и бета-версий. Если что-то сломается, выключите переключатель: лаунчер уберёт файлы сборки и запустит игру только с Fabric API и NovaFX.

### Сборка мода

Вариант А, без установки чего-либо: загрузите папку `nova` в репозиторий на GitHub. Откройте **Actions → build → последний запуск → Artifacts → nova**. В архиве будут `novafx-1.0.0.jar` и `NovaLauncher.exe`.

Вариант Б, локально: установите JDK 25 (например, [Adoptium Temurin](https://adoptium.net)) и запустите `build-mod.bat`. Jar окажется в `dist\`.

Версии сборки взяты из официального шаблона Fabric для 26.3: Loader 0.19.5, Fabric API 0.162.0+26.3, Loom 1.18, Gradle 9.7.1.

## Вход через Microsoft

Входу через Microsoft нужен свой **Client ID** приложения Azure, одобренный Mojang. Без одобрения сервер Minecraft отвечает ошибкой 403.

1. Откройте [portal.azure.com](https://portal.azure.com) → **Microsoft Entra ID** → **App registrations** → **New registration**.
2. Задайте имя. В Supported account types выберите **Personal Microsoft accounts only**. Redirect URI оставьте пустым.
3. Откройте **Authentication** → **Allow public client flows** → **Yes** → Save.
4. Скопируйте **Application (client) ID**.
5. Подайте заявку Mojang на доступ к Minecraft API (форма есть в статье Mojang о регистрации приложений). Понадобятся Client ID, Tenant ID, название и сайт, например страница на GitHub. Одобрение обычно занимает около недели.
6. Вставьте Client ID в лаунчере: **Настройки → Client ID приложения Azure**.

Пока одобрения нет, можно играть с офлайн-аккаунтом: в одиночной игре и на серверах без проверки лицензии.

Токены Microsoft хранятся только у вас, в `settings.json`, и зашифрованы Windows (DPAPI). Расшифровать их может только ваш пользователь Windows.

## Сборка лаунчера

```
cd launcher
go test ./...
set GOOS=windows& set GOARCH=amd64& go build -trimpath -ldflags "-s -w -H windowsgui" -o ..\dist\NovaLauncher.exe .
```

На Linux и macOS `go run .` запускает dev-режим: интерфейс открывается на http://127.0.0.1:8765 с тем же бэкендом. Это удобно, чтобы править интерфейс в обычном браузере.

## Известные ограничения

- `NovaLauncher.exe` не подписан, поэтому SmartScreen может предупредить при первом запуске. Нажмите «Подробнее → Выполнить в любом случае» или соберите exe сами из исходников.
- Мод сделан под 26.3. На других версиях лаунчер запустит игру без NovaFX.
- Окну лаунчера нужен Microsoft Edge WebView2. В Windows 10/11 он обычно уже стоит, а если нет, лаунчер покажет ссылку на установку.
