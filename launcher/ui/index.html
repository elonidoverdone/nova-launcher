Nova

Minecraft на Fabric со своими визуалами. Эффекты ударов, хитмаркер и текст песни настраиваются прямо в игре: нажмите правый Shift.

Включите музыку в Яндекс Музыке — строки песни появятся здесь и в игре.

Моды

Поиск по Modrinth среди модов под Fabric для выбранной версии. Зависимости ставятся сами.

Введите название или нажмите «Найти», чтобы увидеть популярные моды.

Аккаунты

Лицензия Microsoft нужна для серверов с проверкой, офлайн-аккаунт подходит для одиночной игры и серверов без проверки. Аккаунты можно менять и прямо в игре: нажмите на свой ник в правом верхнем углу главного экрана.
